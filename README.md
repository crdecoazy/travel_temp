# Travel Business Management System

A comprehensive system for managing a travel business, including customer booking, driver management, and an admin control panel.

## Features

### 1. User (Customer)
- Register / Login (mobile number + OTP)
- Search vehicles (Car / Van)
- Trip types: One-way, Round trip, Hourly rental
- Fare estimation
- Booking flow (Cash / Online payment)
- Booking history

### 2. Admin
- Dashboard (Total bookings, revenue, active trips)
- Vehicle Management
- Driver Management
- Booking Management
- Pricing Control

### 3. Driver
- Trip Management (Accept/Reject, Start/End trip)
- Navigation

## Tech Stack
- **Backend:** Python (FastAPI)
- **Database:** PostgreSQL
- **Frontend:** React.js
- **Mobile:** React Native (to be implemented)

## Project Structure
- `backend/`: FastAPI application
- `frontend/`: React.js application
